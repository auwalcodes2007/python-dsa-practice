# Python Data Structures & Algorithms Practice

This repository contains my personal implementations, step-by-step problem breakdowns, and extra drill exercises following the **freeCodeCamp / Jovian "Data Structures and Algorithms in Python"** curriculum.

The goal of this repository is to build a deep, first-principles understanding of fundamental algorithms, time/space complexity analysis (Big O), and systematic problem-solving techniques.

---

## 🛠️ Tech Stack & Environment

* **Language:** Python 3.12+
* **Environment:** Jupyter Notebooks inside VS Code
* **OS:** Linux Mint
* **Key Libraries:** `jovian` (test utilities), `ipykernel`

---

## 📌 Problem-Solving Method

Every problem in this repository follows a systematic 6-step framework:

1. **State the problem clearly** in plain English.
2. **Define example inputs & outputs**, including edge cases (empty lists, negative values, duplicates).
3. **Draft a brute-force approach** in plain English/pseudocode.
4. **Implement and test** the brute-force solution.
5. **Analyze efficiency** (Big O Time & Space Complexity).
6. **Optimize** the algorithm and re-test against all edge cases.
